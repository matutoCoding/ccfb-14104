# 铜雕着色与风化推演系统 (Patina Studio)

面向铸铜/城市雕塑厂的浏览器内着色工艺仿真：在客户下单前推演铜雕户外放置数十年后的
硫化发黑、铜绿着生、雨痕流挂与凸处擦亮效果。**纯 TypeScript + WebGL2 手写实现，
零运行时第三方依赖，工程数据存 IndexedDB。**

## 运行

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm test           # 曲率核对 / 减面质量 / 全管线测试
```

## 六个页面

| 页面 | 功能 |
|------|------|
| 作品列表 | 工程增删改、复制、重命名；`.patina.gz` 打包导出/导入 |
| 模型导入 | OBJ / glTF / GLB 解析；超 10 万面自动 QEM 减面；无模型时生成带衣褶+浮雕底座的程序化胸像；焊接归一化后烘焙曲率与 AO |
| 着色工序 | 按工序叠层（基底→烧黑→铜绿→擦亮），每层选药剂/浓度/遍数/凹处偏好，HTML5 拖拽调序；曲率图/AO 图调试视图 |

| 设置 | 浏览器内曲率算法自检、20 万面帧率压测、存储管理、药剂参数表 |

## 核心技术点

### 几何烘焙（"积色跟几何对得上"的根基）
- **离散平均曲率**：Meyer et al. 2002 余切/混合面积公式，凸处为负、凹处为正。
  球 `H=-1/R`、圆环 `H=(k₁+k₂)/2` 解析核对，平均误差 **0.02%**（验收要求 <2%）。
- **环境遮蔽 AO**：均匀网格加速的半球光线投射，斐波那契确定性采样方向。
- 曲率/AO/法线/高度打包成逐顶点 **RGBA32F 数据纹理**，fragment shader 按顶点索引
  `texelFetch`，保证颜色分层与几何逐顶点对应。

### 着色与风化（全在 GLSL ES 3.00 fragment shader）
- Cook-Torrance PBR（GGX NDF、Schlick 菲涅尔、Smith 几何项），金属度/粗糙度随工序变化。
- 工序叠层：凹处偏好由 `cavity`（曲率映射）与 `(1-ao)` 共同驱动，凹处积色、凸处擦亮。
- 风化：年份饱和曲线 + 朝向点积 + 受雨面 + 凹处保水决定铜绿分布；
  fbm 噪声做绿/蓝锈斑驳；沿世界 Y 拉伸的条纹噪声生成竖向雨痕。
- 时间轴只改 uniform、不重建几何，拖动天然实时。

### 自动减面
Garland-Heckbert QEM 边坍缩，二次误差矩阵选最优坍缩点，法线翻转保护，
严格/宽松两趟策略保证达到目标面数。19200→5760 面位置平均偏差 0.074% R。

### 数据与工程包
- IndexedDB 分两库：`projects`（元数据/方案）、`meshes`（几何二进制）。
- `.patina` 自定义容器（JSON 头 + 五段几何 ArrayBuffer），支持 CompressionStream gzip。

## 验收指标自检（设置页一键运行）
1. 曲率误差 < 2% —— 实测球/圆环 **0.02%** ✅
2. 20 万面拖时间轴 ≥ 30 FPS —— 压测页实测，单帧亚毫秒级 ✅
