# 架空线路排杆与弧垂校核系统

浏览器端 110~500kV 架空线路排杆定位与弧垂/距离校核工具。TypeScript + three.js + IndexedDB，无需后端。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
npm test         # 力学内核精度测试（对标手算）
```

## 页面

| 页面 | 功能 |
|---|---|
| 线路工程 | 工程管理（存 IndexedDB）、程序生成"翻山过河"走廊（山包、河谷、树林、公路、低压线）、耐张段一览 |
| 杆塔排位 | 纵断面图上拖塔/放塔、塔型库（直线/耐张/转角）、呼高与串长修改、一键自动排位（最少塔数）、档距实时刷新 |
| 导线工况 | 导线库（截面/单位重/E/α）、气象工况编辑、控制工况与应力设定、状态方程各工况应力表、各档弧垂表 |
| 三维校核 | three.js 三维场景：地形/树/公路/低压线/杆塔/四分裂导线+间隔棒；大风工况导线与悬垂串风偏（风向角可调）；最近点连线与数值标注；拖塔实时重算 |
| 交叉跨越 | 对地/树/公路/低压线最小距离汇总，按控制工况（最高温/大风）校核，点击定位 |
| 成果输出 | 杆塔明细表、各档弧垂表、交叉跨越校核表（不满足的排最前）CSV 导出 |

## 计算依据（《电力工程高压送电线路设计手册》）

- **比载**：γ1 自重、γ2=27.728·b(d+b)/A×10⁻³ 冰重、γ4/γ5 风压（0.625v²）、γ6/γ7 综合比载
- **悬链线精确解**：y(x)=a[cosh((x−x0)/a)−cosh(x0/a)]，a=σ0/γ，高差档不用抛物线近似（近似值并列显示供对照）
- **状态方程**（耐张段代表档距法）：σn−Eγn²lr²/(24σn²)=σm−Eγm²lr²/(24σm²)−αE(tn−tm)，牛顿法解三次方程，lr=√(Σl³/Σl)
- **风偏**：悬垂串摆角 tanφ=(P串+γ4·A·lh)/(G串+γ1·A·lv)，lv 取相邻档最低点间水平距离；导线面按综合比载方向倾斜
- **安全距离**：GB 50545 按电压等级取值（对地/山坡/树木/公路/电力线）

## 精度验证

`test/sag.test.ts` 以 LGJ-400/35 为例对标手算：

- 水平档/高差档悬链线弧垂 vs 抛物线手算值偏差 < 0.5%
- 状态方程牛顿解 vs 独立二分法解偏差 < 0.5%，往返求解还原基准应力
- `test/integration.test.ts` 验证自动排位→应力→弧垂→校核全链路无 NaN、拖塔后实时更新
